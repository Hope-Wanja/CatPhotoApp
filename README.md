# CatPhotoApp

A beginner friendly, HTML webpage built as part of web development practice, featuring cute cat photos, lists of things cats love and hate, and structured media elements.



##  Features

- **Semantic HTML5 Structure:** Uses modern structural tags like `<main>`, `<section>`, `<figure>`, and `<figcaption>`.
- **Media Integration:** Displays responsive images with descriptive `alt` text for accessibility.
- **Lists & Links:** Features both unordered (`<ul>`) and ordered (`<ol>`) lists, alongside external text and image links (`<a>`).
- **Clean Footer:** Includes attribution and links to freeCodeCamp.
